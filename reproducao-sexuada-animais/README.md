# Reprodução sexuada nos animais

Apresentação de Ciências do 8º ano — Professor Luciano Costa. 23 telas / 60 minutos.

## Uso
Abra `index.html` no navegador ou pelo GitHub Pages. Setas e botões navegam; o menu permite escolher uma tela. As cenas têm avanço de etapas, reinício e pausa de rotação. Arraste o modelo para girar. Há redução de movimento, tela cheia e notas do professor.

Cinco telas de quiz apresentam quatro alternativas cada. Selecione uma opção e clique em Conferir resposta. A última tela contém quatro questões abertas.

## Recursos e limites
HTML único, CSS e JavaScript incorporados; ilustrações vetoriais com símbolos do sistema, sem fotografias externas. Modelos geométricos didáticos: gametas, divisões iniciais, ovo e girino. Não representam anatomia realista nem escala. Three.js 0.160.1 via jsDelivr requer internet. Sem WebGL/CDN, usa ilustração alternativa. A aparência dos símbolos pode variar entre dispositivos.

## Tempo
Abertura 1 min; conceitos 14 min; fecundação e desenvolvimento 20 min; metamorfoses e comportamento 15 min; quiz 6 min; atividade 4 min.
