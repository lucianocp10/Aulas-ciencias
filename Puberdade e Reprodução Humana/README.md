# Puberdade, Hormônios e Reprodução Humana

Apresentação interativa de Ciências para o 8º ano, preparada pelo professor Luciano Costa.

[Abrir a apresentação](https://lucianocp10.github.io/Aulas-ciencias/Puberdade%20e%20Reprodu%C3%A7%C3%A3o%20Humana/)

A aula aborda a puberdade e a adolescência, as mudanças corporais e a ação dos hormônios. Apresenta os sistemas genitais, o ciclo menstrual e cuidados com a saúde.

O material está organizado em duas aulas e inclui ilustrações, animações, questões interativas e uma revisão para o caderno. Use os botões de navegação ou o menu para escolher as telas.

O arquivo `index.html` abre a apresentação em um navegador.
